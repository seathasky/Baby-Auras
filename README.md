# BabyAuras

[![Matt's Addons on Discord](https://img.shields.io/badge/Discord-MattsAddons-738bd7.svg?style=flat&logo=discord&logoColor=white)](https://discord.gg/9w6ZdaksDX)

[Curseforge Download](https://www.curseforge.com/wow/addons/babyauras)

BabyAuras enhances World of Warcraft's built-in Cooldown Manager with configurable alerts, freely positioned Solo icons, and additional customization.

![Baby Auras interface preview](https://i.imgur.com/2oidWx5.png)

## Features

<img src="https://i.imgur.com/HVe6GQS.png" width="500">

*   Built from the ground up by me, not AI!
*   Custom audio, text-to-speech, and glow alerts
*   Movable Solo icons and tracked bars
*   Per-icon text, font, color, and display controls
*   Snapping, linked movement groups, and preview tools
*   Full user tutorial to help you get started with BA.
