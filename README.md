# Baby Auras

The cooldown manager addon with an earlier bedtime.

Baby Auras builds on World of Warcraft's Cooldown Manager, adding configurable alerts and freely positioned Solo icons without replacing Blizzard's setup.

## Features

- Built from the ground up by me with love, not AI!
- Custom audio, text-to-speech, and glow alerts
- Movable Solo icons and tracked bars
- Per-icon text, font, color, and display controls
- Snapping, linked movement groups, and preview tools
